# LAB3 – Recurrent Neural Networks (RNN)

## 1. Giới thiệu

Nội dung được tổ chức thành file yêu cầu bài tập và chương trình thực thi từng bài.

- Làm việc với bộ dữ liệu UIT-VSFC và PhoNERT theo yêu cầu của từng bài tập.
